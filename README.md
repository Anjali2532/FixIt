# FixIt

### Report It. Track It. Get It Fixed.

FixIt is a community problem-reporting web application for apartment communities, college campuses and neighborhoods.

Problems like broken lights, leaking pipes and overflowing trash are often reported through calls or messages that are difficult to track. FixIt brings these reports into one place, making it easier to report a problem and follow its progress.

## How It Works

A resident submits a report with a title, category, location and description. They can also attach a photo to help explain the problem.

An administrator reviews the report, assigns someone to handle it and updates its status as work progresses. The resident can check their dashboard to see updates and the report’s history.

## Main Features

- Resident registration and login
- Issue reporting with an optional photo
- Personal dashboard for tracking submitted reports
- Administrator dashboard for managing reports
- Search and filters by category, status and assignee
- Issue assignment and status updates
- Report history with timestamps and notes
- Responsive pages for phones, tablets and computers

## Report Statuses

Reports follow this workflow:

**Reported → Assigned → In Progress → Resolved**

Administrators can reopen a resolved report if the problem returns.

## Planned Technology Stack

- **Frontend:** React, JavaScript, HTML and CSS
- **Backend:** Python and Flask
- **Database:** PostgreSQL
- **Database access:** SQLAlchemy
- **Backend testing:** pytest and the Flask test client

## Project Scope

The first version focuses on submitting reports, managing assignments and tracking progress. Maps, notifications, voting and native mobile apps are outside the initial scope.
